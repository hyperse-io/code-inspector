# About Code Inspector

**Code Inspector** is developed by [Hyperse](https://github.com/hyperse-io) as
part of a broader developer-experience toolkit alongside projects such as
[Hyperse HPS](https://hyperse-io.github.io/hps/) and
[Hyperse Wizard](https://hyperse-io.github.io/wizard/).

The documentation you are reading is built with
[Fumadocs](https://fumadocs.dev) on [Next.js](https://nextjs.org) and deployed
to GitHub Pages.
